# Simple Repeating Pattern

## Profile Image

![pd-profile|160](../../assets/types/simple-repeating-pattern/profile/simple-repeating-pattern-image.svg)
The foundational structural category in surface pattern design: a motif or group of motifs tiled seamlessly across a surface using a defined repeat layout. The key property is that the unit tiles without visible seams or breaks in any direction.

## Overview

A simple repeating pattern is a design in which one or more motifs are systematically duplicated to create an infinitely continuous surface. The repeat unit — the smallest tile that contains the complete design — is placed according to a layout rule that governs how tiles relate to each other spatially. Understanding these layout rules is considered one of the core technical competencies of surface pattern design. Once motifs are established, a designer can produce multiple coordinating patterns by applying different repeat layouts to the same elements.

## Visual Characteristics

Appearance varies entirely by layout type and motif. Full-drop repeats produce formal, grid-aligned compositions. Half-drop and brick offsets create diagonally flowing movement that reads as more informal and organic. Tossed repeats appear scattered and energetic. Diamond and ogee repeats generate strong diagonal rhythm. Stripe layouts create bold directional emphasis, whether built from solid colour blocks, motif rows, or textural bands.

## Pattern Structure

Seven primary repeat layouts are used in commercial surface pattern production:

- **Full Drop (Block):** Motifs stacked in an aligned horizontal and vertical grid. The simplest construction; produces a formal, structured look. Tiles can be square or rectangular.
- **Half Drop:** Motifs arranged in vertical columns, each column offset vertically by 50% relative to its neighbour. Reduces rigidity and introduces diagonal movement.
- **Brick:** Same offset principle as half drop but applied horizontally — each row is shifted by 50% of the tile width. Resembles a brick-wall bond.
- **Diamond:** Elements arranged in diagonal rows by placing the repeat unit on a rotated axis, producing a diamond-shaped grid.
- **Ogee:** A repeat based on an S-curve outline — pointed at top and bottom, curved at the sides — producing a grid of interlocking arch shapes.
- **Tossed (Random):** Motifs scattered organically within the repeat unit. The edges must still tile seamlessly, but the internal layout avoids linear alignment. Produces the most informal, all-over surface feel.
- **Stripe:** A layout with strong vertical, horizontal, or diagonal directional emphasis. Stripes may be solid colour fields, bands of texture, rows of motifs, zigzags, or wavy lines.

Within a pattern collection, a hero pattern (the most complex and motif-rich design) is often produced as a tossed repeat, while coordinating patterns use simpler layouts — dot, stripe, or block — drawn from the same motif vocabulary.

## Common Motifs

The simple repeating pattern is a structural category, not a motif category. Any motif — floral, geometric, conversational, abstract — can be executed as a repeating pattern. The repeat layout is the defining characteristic, not the subject matter.

## Colour and Style

No fixed palette. Repeat structures are layout rules independent of colour. However, full-drop and stripe layouts typically suit bold, graphic colour choices, while half-drop and tossed layouts handle complex multi-colour motif arrangements well.

## History and Context

Seamless repeat construction has been a technical requirement in textile production for centuries, from hand-block printing to Jacquard weaving. The industrialisation of fabric printing in the 18th and 19th centuries formalised the repeat unit as a production concept. Digital tools — particularly Adobe Illustrator — have made repeat construction more accessible, and repeat types are now a standard element of surface pattern design education.

## Surface Pattern Uses

Repeat pattern structures are universal across all surface pattern markets: apparel fabrics, furnishing textiles, wallpaper, gifting wrap, stationery, bedlinen, and print-on-demand platforms. The choice of repeat type affects both the technical production requirements (fabric yardage efficiency, print registration) and the visual character of the finished product. Half-drop and brick repeats are particularly common in wallpaper and furnishing fabric production.
