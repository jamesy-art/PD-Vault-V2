# types-of-repeat-pattern

A structural overview of the core repeat systems used to tile a motif across a surface — the foundational technical vocabulary of surface pattern design.

## Overview

Surface pattern designers rely on a small set of standard repeat systems to arrange a motif or repeat unit across a continuous surface. These systems are structural rather than aesthetic — the same repeat can be applied to any motif, colourway, or style — and choosing between them is one of the first technical decisions in constructing a seamless pattern. The source identifies seven of the most common: full drop, half drop, brick, diamond, ogee, tossed/random, and stripe.

## Visual Characteristics

Each repeat produces a distinct visual rhythm. Full drop reads as an ordered, grid-like arrangement. Half drop and brick both break up that grid by offsetting alternating rows or columns, producing a less formal, more organic-feeling surface despite being mathematically regular. Diamond and ogee repeats arrange motifs along diagonal or lens-shaped paths, giving the surface a more ornamental, structured character. Tossed/random repeats read as loose and organic, with no visible grid. Stripe repeats establish a strong directional (vertical, horizontal, or diagonal) format.

## Pattern Structure

- **Full drop / block repeat** — the repeat unit is stacked directly in a grid, in square or rectangular units; the simplest and most common repeat system.
- **Half drop repeat** — the repeat unit is stacked in vertical columns, with each column offset by half the unit's height relative to its neighbour.
- **Brick repeat** — the same offset logic as half drop, but applied horizontally, so rows are offset by half the unit's width, resembling brick coursing.
- **Diamond repeat** — the repeat unit is arranged as a repeating diamond shape, producing diagonal rows of motifs.
- **Ogee repeat** — similar to the diamond repeat but with rounded sides and pointed top and bottom (an onion-like silhouette).
- **Tossed / random repeat** — motifs are scattered within the repeat unit without a fixed grid, producing an unstructured, organic result.
- **Stripe repeat** — a layout built on a strong vertical, horizontal, or diagonal format; stripes can be solid colour blocks or built from texture, motifs, zigzags, or wavy lines rather than flat colour alone.

## Common Motifs

This is a structural category rather than a motif category — any motif can be arranged using any of these repeat systems. The source does not tie specific motifs to specific repeats.

## Surface Pattern Uses

Repeat structure is foundational to all surface pattern design output — fabric, wallpaper, stationery, and packaging all depend on one of these repeat systems (or a combination of them) to tile a motif seamlessly across a surface. The choice of repeat affects perceived formality, density, and movement in the finished design.
